# Data and privacy

This repository was built from new fictional fixtures. It contains no employee records, customer records, patient records, personal newsletter content or proprietary writing examples.

Runtime databases, local environment files, API credentials and logs are excluded from Git. Keep the application bound to localhost and use synthetic data only. The demo identity controls are not real authentication.

Before publishing changes, review `git diff --cached` and `git ls-files`. Never add runtime databases or personal documents. A public repository exposes its source code, committed data and history; it does not inherently expose your separate local data files.
